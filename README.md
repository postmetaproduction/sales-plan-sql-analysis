# Анализ выполнения плана продаж с помощью SQL

## О проекте

Учебный SQL-проект по анализу плановых и фактических продаж сети автозаправочных комплексов (АЗК).

Идея проекта появилась после знакомства с рабочими отчётами по выполнению планов продаж. Для практики я создала отдельный набор вымышленных данных.

## Цель

С помощью SQL определить, какие АЗК выполняют план продаж, какие отстают и как отличаются результаты по городам за несколько месяцев.

## Данные

В проекте используются две таблицы:

- **sales** — 50 записей о плановых и фактических продажах 10 АЗК за январь–май.
- **stations** — 10 записей с информацией о городах и регионах расположения АЗК.

Все данные учебные и вымышленные. Реальная корпоративная информация не публикуется.

## Что я сделала

- Создала таблицы и заполнила их учебными данными в SQLite.
- Написала запросы для поиска АЗК, не выполнивших план.
- Рассчитала отклонения от плана в рублях и проценты выполнения.
- Использовала SUM, GROUP BY и HAVING для анализа результатов за несколько месяцев.
- Объединила таблицы с помощью JOIN.
- Проанализировала суммарные продажи и выполнение плана по городам.

## Использованные технологии

- SQLite
- SQL: SELECT, WHERE, JOIN, GROUP BY, HAVING, SUM, ROUND, ORDER BY

## Результат

Получила сводные данные по выполнению плана продаж на уровне отдельных АЗК и городов.

Проект выполнен для практики SQL и анализа данных.
